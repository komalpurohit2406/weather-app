# 🌦 Weather App

A modern weather application built using HTML, CSS and JavaScript.

## Features

- 🌤 Live weather data
- 📍 Search weather by city
- 🌡 Temperature
- 💧 Humidity
- 🌬 Wind Speed
- 🌅 Sunrise & Sunset
- 🎨 Dynamic UI
- 💎 Glassmorphism Design
- 📱 Responsive Layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
